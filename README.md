# NXFW

Nintendo Switch firmware repository with automatic updates.

## Latest Releases

All firmware versions are available in the [Releases](https://github.com/sthetix/NXFW/releases) section.

## Download

1. Go to [Releases](https://github.com/sthetix/NXFW/releases)
2. Download the desired `FW-X.X.X.zip` file
3. Extract and use as needed

## Version Format

Firmware files follow this naming convention:
- `FW-X.X.X.zip` (e.g., FW-21.2.0.zip)

## Automatic Updates

This repository is automatically updated when new firmware is released by Nintendo.
