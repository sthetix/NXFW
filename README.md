# NXFW

Firmware repository with automatic updates.

## 📦 Latest Releases

All firmware versions are available in the [Releases](https://github.com/sthetix/NXFW/releases) section.

## 🔄 Updates

This repository is automatically updated with the latest firmware versions as they become available.

## 📥 Download

1. Go to [Releases](https://github.com/sthetix/NXFW/releases)
2. Download the latest `FW-X.X.X.zip` file
3. Extract and use as needed

## 📋 Version Format

Firmware files follow this naming convention:
- `FW-X.X.X.zip` (e.g., FW-20.5.0.zip)
